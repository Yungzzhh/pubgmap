# 多地图离线测距

日期：2026-10-26

## 已确认范围

用户确认先增加米拉玛（沙漠）、萨诺（雨林）、维寒迪（雪地）、泰戈及帝斯顿，保留原艾伦格，共六张地图。

- 从地图左上角名称选择地图，手机与桌面均可操作。
- 萨诺使用 4096 米坐标边长；其余五张使用 8192 米。维寒迪使用官方仓库提供的新版 8×8 km 素材，不沿用旧 6×6 km 的换算。
- 测距、比例尺、100 米/1 公里网格及 700 米参考圈使用当前地图的换算。
- 每张地图在本次打开期间独立保留定点和视角，切换时不混用；下次打开只记住上次选择的地图。
- Reset 只清除当前地图定点和结果，保留视角。原双指缩放、拖动及连续更换目标的行为不变。
- 全部地图随应用预缓存；只有全部资源检查完成才显示「离线就绪」。
- 保留现有 PWA 的 id、scope、start_url 和部署地址，沿用本会话已授权的 GitHub Pages 发布流程。

## 验收

1. 六张地图均能选择、加载并在已知坐标下测出 500 米。
2. 萨诺同样归一化跨度的距离是其他 8 km 地图的一半，网格和比例尺同步变化。
3. 切回原地图时恢复该地图的点和视角；Reset 不影响当前视角或其他地图。
4. 切换时取消旧地图未结束手势，加载完成前不能误定点。
5. 手机小屏、横屏不溢出，选择器可触达。
6. 生产环境断网后仍可切换六张地图、刷新、冷启动并测距。
