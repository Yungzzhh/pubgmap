# Windows 绿色便携版

日期：2026-10-26

## 已确认需求

- 用户要求 Windows 应用，通过解压后直接运行 EXE 使用。
- 六张地图和运行时随应用内置，首次启动也可完全断网；使用独立桌面窗口。
- 保留六地图切换、两点测距、滚轮/双指缩放、拖动、网格及 Reset 保留视角。
- 使用 Electron 复用已验证的测距逻辑；运行时无须安装 Node.js、浏览器或启动本地服务。
- 交付目标为 Windows 10/11 x64，ZIP 内包含 EXE 及其必要运行文件，应完整解压后运行。
- 便携数据保存于 EXE 旁的 `data/`，更新或移动应用时可连同数据一起保留。
- 桌面版本去除手机安装及联网缓存流程；地图读取来自程序包，阻止外部网络请求和导航。
- 当前 macOS 工作机不能代替 Windows 验收，使用 Windows 构建环境生成成品并对 EXE 做启动与测距检查。

## 验收

1. 干净解压的 ZIP 包可以通过 EXE 启动，六张地图均可加载并完成已知 500 米测距。
2. 无外部网络即可首次启动和切换地图，且不会注册 Service Worker 或提示安装 PWA。
3. Reset 保留视角，切换地图保留各自测量状态，重新启动保留所选地图。
4. 桌面窗口正确限制本地资源范围、网络访问和渲染进程权限。
5. Windows 构建后实际启动 EXE 验证，保存验证记录、校验值及可下载的 ZIP 产物。
