# 艾伦格离线测距 PWA

日期：2026-10-23

## 已确认需求

- 手机使用，部署到 GitHub Pages，支持安装到主屏幕并离线启动。
- 使用 PUBG 艾伦格原始地图资源，随应用缓存，不依赖在线地图或后端。
- 单指轻点依次设置迫击炮位置和目标，第二点确定后即时显示水平直线距离（米）。
- 支持单指拖动、双指缩放；手势结束不能误触定点。
- Reset 清除两点及测距结果，严格保留缩放比例和地图平移位置。
- 完成两点后再次轻点仅更新目标，便于同一炮位连续测距。
- 显示 PUBG 迫击炮 121–700 米射程提示；距离结果不包含高差或弹道修正。
- 离线状态必须以缓存检查结果为依据；网络离线且缓存未完成时不能显示“离线就绪”。

## 部署

用户已授权继续常规开发并部署到 GitHub。账号为 `Yungzzhh`，默认仓库名使用当前项目名 `pubgmap`，预期网址为 `https://yungzzhh.github.io/pubgmap/`。

## 验收

1. 已知地图坐标的距离、屏幕与地图坐标换算正确。
2. 缩放或平移不改变已选点实际距离；Reset 保持视角。
3. 拖动、双指缩放、取消触摸不产生误触标记。
4. 生产构建在 `/pubgmap/` 子路径运行；缓存覆盖页面、脚本、样式、地图、图标和 manifest。
5. 浏览器断网后刷新仍可加载地图并完成测距。
6. 手机上无横向溢出，关键按钮可触达；安装与真实设备行为另列验收边界。
