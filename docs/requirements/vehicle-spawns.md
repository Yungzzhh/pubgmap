# 载具刷新点

日期：2026-10-27

## 用户已确认

- 地图同时标注固定刷新点及随机可能刷新点。
- 区分汽车与飞机；飞机按动力滑翔机处理。
- 继续面向 Windows 便携应用，数据随程序包保存并可离线使用。

## 实现范围

- 内置 257 个有来源的社区参考点：艾伦格 97、米拉玛 82、维寒迪 34、泰戈 34、帝斯顿 10；萨诺没有可靠预置数据。
- 资料不是完整、实时刷新清单。帝斯顿预置只有飞机点；固定类型依照社区标注，受游戏模式与版本影响。
- 来源为 MIT 的 JanJastrow/KampfKarten，资料快照为 2025-12。保留来源哈希、许可、原编号及转换方法。
- 原资料由 Leaflet EPSG3857 显示，其 y 值先映射纬度再做墨卡托投影；不能直接除以 8192 叠加到本项目底图。
- 汽车与飞机采用不同图标及颜色；固定点实心、可能点空心。可按两种载具、两种刷新类型及图层总开关分别筛选。
- 六张地图均支持手工记录。进入记录模式后点击地图保存载具类型、刷新类型、地图及归一化位置，结束后恢复测距。
- 自记点和筛选设置保存于便携版 data 目录对应的本地存储；重开应用后保留。撤销只移除当前地图最后一个自记点。
- Reset 只清测距点，载具图层不拦截地图点击；平移、缩放、切换地图均保持坐标准确。
- 无效或未来版本的本地记录保持只读，保留原数据；保存失败时不把未保存点展示为成功记录。

## 验收

坐标转换、类型筛选、地图隔离、持久化和异常存储先以失败测试确认，再实现；实际界面及 Windows EXE 还需验证载具图层、手工记录、Reset 不删除点、重启恢复，以及原六图测距回归。
