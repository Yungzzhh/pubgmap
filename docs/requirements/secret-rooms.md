# 密室位置与地图图标尺寸

日期：2026-10-27

## 用户要求

在当前 Windows 便携版地图中添加密室位置，已有地图点位图标再缩小 50%。

## 实现约定

- 独立「密室位置」入口；金色钥匙代表原资料的 secret_room，橙色房屋代表 bunker。两类可分别开关，避免把所有掩体都当作钥匙密室。
- 使用 MIT 的 JanJastrow/KampfKarten，2025-12 社区快照；2026-10-27 重新在线核对 tree 与源文件哈希。
- 共 43 个密室点（艾伦格 15、泰戈 15、帝斯顿 13），17 个掩体点（艾伦格 4、米拉玛 3、维寒迪 10）；萨诺暂无可靠预置资料。社区资料不保证完整或适用于所有版本，开启条件以游戏为准。
- 沿用已验证的纬度网格到 EPSG3857 底图转换，不直接将源 y 除以 8192。
- 汽车、飞机、密室与掩体图标连同底圈、用户标识整体缩小 50%，不缩放地图坐标、按钮或测距 A/B 标记。内部 14 px 图形绘制为 7 px 视口，20 px 底圈直径绘制为 10 px；地图缩放不改变标记尺寸。
- 点位及许可随程序保存，可首次断网运行；密室图层不拦截测距点击。
- 密室筛选使用独立键 pubgmap.secret-rooms.v1，保留 v1.3 汽车/飞机记录及格式。异常设置只读保留，保存失败时恢复原勾选状态。
- Reset 保留图层、视角、载具记录；关闭或切换应用后恢复筛选。

## 验收

先验证新增模块缺失时测试失败，再实现数据、筛选、存储与图标绘制。Windows 实际 EXE 验证六图预置点数、图形真实尺寸、筛选独立性、坐标与缩放一致、在图标处测距、Reset 保留及完整重启恢复。
