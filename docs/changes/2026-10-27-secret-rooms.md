# Windows v1.4 密室位置与小图标

日期：2026-10-27

## 使用

右上角点「密室位置」，分别勾选「钥匙密室」和「地下掩体」。金色钥匙与橙色房屋标记分别表示两类位置。地图上的汽车、飞机、密室及掩体图标已整体缩小 50%，可继续直接点击对应位置测距。

密室筛选自动保存到本机，和载具筛选相互独立。Reset 只清测距定点，保留当前视角、图层与自记载具记录。更新应用时保留 EXE 旁的 data 文件夹。
